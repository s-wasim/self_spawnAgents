# Frozen-Path Changelog

Every legitimate change to a path in `FROZEN_PATHS` requires an entry here.
Entries are append-only. Schema:

```
## <ISO date> — <path> — <sha256 before> → <sha256 after>
<signed note: operator initials + rationale>
```
